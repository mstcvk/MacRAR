## MacRAR 1.0

Signed with Developer ID and notarized by Apple: open the DMG, drag MacRAR to Applications, done. No Gatekeeper warnings.

**What's inside**
- Browse, extract, test, create and edit RAR, 7z, ZIP, TAR and 30+ other archive formats (RARLAB `unrar`/`rar` + 7-Zip `7zz` engines bundled).
- Encrypted archives (RAR, 7z, ZIP/AES), multi-volume sets, drag-to-Finder extraction, progress window with ETA.
- Finder Quick Actions: Extract Here / to Folder / To…, Test, Compress, Create Archive…
- English and Turkish interface, following the system language.

**Requirements:** macOS 13+, Apple Silicon. Creating RAR archives needs a WinRAR licence (bundled `rar` is the trial); everything else is free.
