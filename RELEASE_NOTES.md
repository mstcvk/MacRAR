## MacRAR 1.1

Signed with Developer ID and notarized by Apple: open the DMG, drag MacRAR to Applications, done.

**New in 1.1**
- Finder right-click menu: *Open with MacRAR*, *MacRAR: Extract Here*, *MacRAR: Extract to Folder* (for archives) and *Compress with MacRAR…* (for any selection) now appear directly in the context menu instead of only inside the Quick Actions submenu. *Extract To…*, *Test* and the one-click *Compress (RAR)* stay in Quick Actions.
- The installer enables the Finder services automatically; no trip to System Settings needed.
- Local builds are signed with the Developer ID certificate when one is present.

**Highlights**
- Browse, extract, test, create and edit RAR, 7z, ZIP, TAR and 30+ other formats (RARLAB `unrar`/`rar` + 7-Zip `7zz` bundled).
- Encrypted archives (RAR, 7z, ZIP/AES), multi-volume sets, drag-to-Finder extraction, progress window with ETA.
- English and Turkish interface, following the system language.

**Requirements:** macOS 13+, Apple Silicon. Creating RAR archives needs a WinRAR licence (bundled `rar` is the trial); everything else is free.
